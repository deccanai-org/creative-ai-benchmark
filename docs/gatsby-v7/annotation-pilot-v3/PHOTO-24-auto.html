Lunara Chronometry - Autumn watch campaign: auto verifiers

297 checks answered automatically: the task's 53 automatic checks, unchanged from the V7 site, and 244 human checks now answered automatically: 228 checks by code and 16 checks by a vision model. The code reads the delivered file directly (PDF and SVG text, fonts, sizes and colours), reads images and video frames by OCR, and measures pictures against the supplied files. The vision model (Gemini 3.8 Flash, temperature 0, on Google Vertex) answers only objective questions about a file (copy this text exactly, count these, is this cut off); it never sees the expected answer, code compares what it reports with the rule, each question is asked twice with fixed settings and both answers must agree, and every answer is saved so a re-run gives the same result. Rules it answers carry the Vision model label. Every check answers pass, fail or person: person means it could not be decided, so a person answers that row.
