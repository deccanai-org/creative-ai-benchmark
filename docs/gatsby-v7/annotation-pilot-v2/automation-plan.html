How the automatic checks stay safe

  • Deterministic: fixed tool versions (Tesseract 5.5.3, OpenCV 5.0.0, PyMuPDF 2.0 on MuPDF 1.28.5) and fixed settings, so the same file always gets the same answer.
  • Never a false pass from a failed read: if code cannot find or read what it needs, that check is not answered automatically and a person answers it.
  • "Nothing of this kind appears" checks on images pass only when OCR has read every piece of text clearly.
  • Each pass rule comes from the check's own wording, including any allowance it states (for example "in any letter case", "in any clear form such as 25 SEP").
  • Every converted check keeps its check ID, K question and critical flag.
