Verifier measurements

Use the method beside each check. Look means inspect the named output and reference. Measure means use the stated measurement before answering Yes or No.

Scoring: targets marked Not scored in coverage remain design instructions, but are excluded from the score denominator. They are not passes or failures. If a listed measurement cannot be completed, leave it unanswered and name the missing evidence. Historical pilot results are not scores against this revision.

Review time has not been calibrated. Measurement checks can take longer than visual checks.

Colour matching

  • Sample a flat interior, not an anti-aliased edge, shadow or photograph. Use an sRGB measurement copy.
  • Images and PDFs: each R, G and B value must be within 5 of the stated colour. Video stills: within 10. The Verda wordmark checks explicitly use within 4. SVG colour-value checks use the exact file value.
  • For print PDFs, convert through the embedded/output profile to sRGB using Relative Colorimetric and black point compensation. Use the supplied print profile when the task explicitly names it. Do not guess an absent profile.
  • Use native image dimensions. Rasterise PDFs at 300 ppi for area measurements. Save video stills at native dimensions; examine every distinct held design state. Follow a check's specific time window when given.

Accent area

  1. Read the check's named region and limit. Make a same-size, opaque black-and-white mask: white includes the region; black excludes everything else. Exclude photographs and transparent canvas. Include text unless the check excludes it. Use hard mask edges, with no grey pixels.
  2. For VECTOR-04, include only visible inked artwork. For PHOTO-06, include only the added caption margin. For the LAYOUT-12 deck, exclude embedded poster previews. Test each page or held video frame separately.
  3. Enter the accent hex colours named in the check or brand palette, the matching tolerance, and the percentage limit. The result uses the unrounded percentage. Keep the image, mask and counts as evidence.

Files are processed in your browser only. Nothing is uploaded. Incorrect masks produce incorrect measurements; the reviewer must confirm the mask covers the stated region.
